   вердикты зоны → `impl_sync.visual_review` через `/product:impl-sync` Step 4a (V-23).
3. **Тест утверждает ФАКТ текущего кода** (зелёный прогон); расхождение с каноном — аннотация
   `documented-hole` со ссылкой PA/CD. Канонический `playwright.config.ts` и `_helpers.ts` НЕ мутировать.
4. **VM — общий ресурс:** §0-проба перед разрушающим; docker compose up/down/stop ЗАПРЕЩЕНЫ
   (M16 ERR-01); staging (:3000/:3001) и radar-* не трогать; `.env` не править — env префиксом.
   **БД у dev и staging ОБЩАЯ** — каждая запись стенда видна staging (в брифах — реестр мутаций).
5. **ctx-гейт: пороги по СТАТУСЛАЙНУ сессии** (50/60/70), НЕ по ctx-probe — probe завышает ~×5
   на 1M-окнах и слеп на двухсессионном cwd (калибровка: `vm-factory-ops` §4.1). Сверка изображений
   жгёт окно: ≤1 зона на сессию, между зонами — RESUME-шов.
6. **Обрывы API — норма среды** (6+ за прошлый заезд): инкрементальная запись (1 запись = 1 append,
   коммит по группе), recovery по контент-маркерам, НЕ по diffstat и НЕ по памяти оборванного хода.
