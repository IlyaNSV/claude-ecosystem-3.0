## Петля (единица = зона/FM)

1. **Предпосылки зоны**: env-флаги dark-фич (префиксом, `.env` не трогаем), seed-состояния под экраны
   (paywall-пользователь, admin, фикстурные джобы/сегменты), доступность маршрутов.
2. **Съёмка факта**: playwright-обходчик зоны — spec, доводящий приложение до КАЖДОГО SI-состояния
   (включая модалы/ошибки/empty) и снимающий скриншот в `test-results/visual/<MK>/SI-n.png`
   (+ video/trace при `UJA_HEADED` после Волны B). Дом спеков — `tests/uja/` (канон).
3. **Сверка моими глазами**: Read пары изображений факт↔ToBe + текстовый слой MK §2 (PNG может быть stale —
   тогда опора текст) + DS-токены; выход — поэлементная таблица расхождений методикой SI-2-сверки
   (вердикты: СОВПАДАЕТ / РАСХОДИТСЯ / нет в макете / нет на странице).
4. **Фиксация**: расхождения → PA (функциональное/конфиг) / C-DRIFT (визуальный дрейф) — канон заезда 2026-08-04/05.
5. **Фиксы кодом**: отдельная executor-сессия (НЕ ревьюер — executor/reviewer separation) берёт очередь
   PA/CD зоны и чинит; PA-124..130 + CD-17..19 — готовая затравка первой зоны.
6. **Re-run**: съёмка заново → повторная сверка → до чистоты зоны.
7. **Вердикт зоны**: владелец смотрит пары/видео → `impl_sync.visual_review` через approve-gate impl-sync
   (Step 4a) — ратификация либо conforms, либо deviations-accepted с перечнем.
