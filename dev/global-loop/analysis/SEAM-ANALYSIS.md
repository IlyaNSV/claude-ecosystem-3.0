Общая стоимость прогонов: 30.50M токенов (исполнители 15.20M + пульт 15.29M), 58.2 ч активного времени. 3 из 4 переоткрытий — одна тема: «приёмка не ловит базовых ошибок».
- **Устойчивость судейства:** на слепой переоценке 10 из 14 вердиктов сместились — все в сторону **большего** успеха; причина в неполноте пакета (видел только пилот), не в судье. Метод-урок: инвентарь свидетельств обязан покрывать все репозитории.
- **M11 spec-drift:** 38 артефактов — 55.3% соответствуют, 34.2% частично, 10.5% устарели, 0 фантомов целиком; **drift velocity 16 дней**. - **Rework:** строго **22.9% сессий / 21.1% токенов**, широко **42.9% / 55.4%**. Три источника: гейт-петля RUN-A 24.6% токенов (**5 вердиктов NO-GO имели один механический корень — диагностирован пятикратно**), пост-hoc достройка приёмки 24.3%, обрывы сессий 17.5% (один — ошибка пульта: ложный сигнал монитора убил живой процесс). Ни один артефакт не переписывался >3 раз, проходы сходящиеся.
- **ROI / мультипликатор:** владельческое время **31.6 ч** (кластеры сообщений, 47 подходов) против 58.2 ч машинного → **мультипликатор 1.8:1**. Заявленное в журнале внимание (28.8 ч) отличается от факта на 10%.
- **Открытые дефекты:** 61 из 162, из них **47 (77%) — класса «нет такого гейта»**; крупнейшая группа — acceptance-gap (17).
- **Конверсия уроков в канон (проверено grep, не по claim):** внесены P8 UJA (DEC-DEV-0225), Release DoD (DEC-DEV-0221), I-8 (CONDUCTOR.md). **Главный вывод, к которому сошлись три независимых замера:** экосистема эффективна ровно настолько, насколько её правила материализованы в машине. Сильные оси спек — те, у которых есть носитель в шаблоне (M10); не дрейфуют только артефакты-входы кодогенерации (M11); 60% дефектов приходится на зоны, где гейта не существует.
