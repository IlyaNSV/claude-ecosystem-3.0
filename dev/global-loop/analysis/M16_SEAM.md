### Инварианты и запреты (решены — НЕ пересматривать)

1. **Никакой профанации протокола — это главный инвариант.** Замер посвящён тому, как срезание
   процесса ради скорости портит результат. Срезать протокол самого замера — значит уничтожить его
   смысл. Если шаг кажется дорогим или избыточным — **стоп и вопрос владельцу**, а не «оптимизация».
2. **Приёмочный набор пишется ДО запуска плеч и не показывается исполнителям.** Он фиксируется
   коммитом с меткой времени раньше старта прогонов. Написать его после — значит подогнать критерий
   под увиденное; результат тогда недействителен.
3. **Исполнителям не сообщается об эксперименте.** Ни в задании, ни в переписке, ни намёком.
4. **Судья слеп:** результаты обезличиваются, порядок предъявления реверсируется, вердикт
   засчитывается только при согласии обоих порядков. Судья не участвовал ни в одном плече.
5. **Задание для плеч побайтно одинаково** (кроме одной вводной фразы про доступный инструментарий).
   Любая правка задания одному плечу — правка обоим, с фиксацией в протоколе.
6. **Плечо B — это B2** (решение владельца): Claude Code + MCP-мастхэвы для веб-разработки, без
   инсталляции экосистемы. Не ослаблять контроль: слабый контроль обесценивает победу канона.
7. **VM read-only снято ТОЛЬКО для стендов эксперимента.** Чужие сессии не трогать (обязательна
   проба занятости), рабочий пилот `~/projects/my-first-test` **не мутировать** — его HEAD сверяется
   до и после и фиксируется в отчёте.
8. **Токены не лимитируются** (решение владельца), но **считаются** — по `output_tokens` каждой
   записи, включая субагентов. Метрика `totalTokens` харнесса — пиковый контекст, а не расход
   (урок M13, занижение в 9.4 раза); ею не пользоваться.
9. **Уборка обязательна** и подтверждается в отчёте перечнем: что удалено, что сохранено, чем
   проверено.
10. **Merge в `main` — только владелец.** Ledger-ветка `docs/global-loop-assist-ledger` пушится свободно.
11. Владельческий класс решений (деньги, прод, реальные секреты) — эскалация; ответ даётся
    **одинаково обоим плечам**.

## Грабли среды (оплачены предыдущей сессией — не переоткрывать)

- **Клон пилота с GitHub зависает** (pack timeout). Клонировать **с VM по ssh**:
  `GIT_SSH_COMMAND="ssh -p 2222 -i ~/.ssh/vm-claude-factory" git clone cc-dev@127.0.0.1:/home/cc-dev/projects/my-first-test <dst>`
- **ssh с кавычками из PowerShell ломается** — передавать скрипт через stdin: `ssh ... 'bash -s' < script.sh` (Bash-инструмент).
- **Сеть (git push / gh / ssh) требует `dangerouslyDisableSandbox: true`** — иначе таймаут порта 443.
- **Токены субагентов лежат отдельно** — в `<session-id>/subagents/**`, в основном транскрипте их нет;
  harvest, копирующий только основной файл, теряет 27–67% расхода.
- **`totalTokens` харнесса — пиковый контекст, а не расход** (занижение в 9.4×). Считать по
  `message.usage.output_tokens` каждой assistant-записи.
- **Тесты пилота не изолированы от окружения:** на чистом клоне без БД/redis падает 308 из 649 тестов
  `apps/api`. Приёмку гонять только на поднятом стенде.
- **StrykerJS не запускается в pnpm-монорепе пилота** (`Cannot find TestRunner plugin "vitest"`) —
  если понадобится мутационная проба, использовать `scripts/mini-mutation.cjs`.
- **Таймзоны:** интенции датируются UTC, коммиты `+0300`, merge-коммиты GitHub `+0600`. При окнах
  атрибуции нормализовать TZ и **не исключать merge-коммиты** (`--no-merges` теряет мержи PR).
- **Скрипты анализа запускать из корня worktree**, не из `scripts/`.
- **Один и тот же прогон печатается разными формами** (`874/874` ↔ `874 passed`) — при поиске
  машинного следа искать мультиформатно.
