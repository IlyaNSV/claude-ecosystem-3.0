**Грабли Windows-хоста, оплаченные этой стройкой (не переоткрывать):**
- `wt.exe` режет аргументы по `;` (разделитель субкоманд) — экранировать `\;`, иначе
  env-цепочки (`$env:X='1'; claude`) молча разваливаются на «вторую вкладку»;
- `Start-Process` (PS 5.1) НЕ квотирует аргументы с пробелами — титул «проект · bypass»
  превращался в команду (`0x80070002`); командную строку wt собирать с ручным квотингом;

  `.Length` — учитывать при паддингах;
