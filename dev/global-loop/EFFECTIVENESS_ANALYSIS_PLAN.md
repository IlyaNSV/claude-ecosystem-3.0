## 1. Вопросы владельца (интенции — дословно, что анализируем)

1. Эффективность работы **самой экосистемы** (процессы P1–P8, гейты, артефакты) на материале RUN-A/RUN-B.
2. Эффективность **управления ею** (кондуктор-слой, Волна 0 ассист-пульт).
3. **Мост «интенция → код»** (добавлено владельцем 2026-07-28, включены ВСЕ предложения M1–M6):
   > «мне надо понимать насколько эффективен мост от "интенции через хост пульт" → множество механизмов экосистемы → фактические изменения в коде. Нет ли такого, что экосистема переусложняет или переписывает одно и то же по 10 раз, т.к. у меня сложилось представление, что мы запускаем сложную фабрику, которая дает маленький выхлоп […] я пишу у нас проблема "х", экосистема работает 30 минут – час, а по факту эта же проблема остается или решается на маленький процент. Поэтому есть ощущение, что кодовая база может деградировать, хотя комплексные процессы экосистемы "по бумагам" работают.»

Контр-рамка (держать честность в обе стороны): у экосистемы есть и контр-свидетельства (UJA ловила классы, невидимые «сырому Claude»; 0 NO-GO; feedback-контур сам вскрыл 9 находок). Вопрос анализа — не «фабрика плохая?», а **какой ценой единица интенции превращается в единицу решённой проблемы** и куда тренд.

## 9. Методологическая рамка

- **Пре-регистрация метрик ДО подсчёта**; судья-модель фиксирована между сравниваемыми плечами; executor-выводы не грейдят сами себя (D7-паттерн `blind-comparison-protocol.md`).
- MDP-пиновки: экстракция — скрипты/sonnet; анализ классов — opus; синтез/вердикты — main.
- Замеры «по бумагам vs по факту» разделять явно: процессные прокси (гейт PASS) ≠ intent-исход.
- Кандидаты-фреймворки метрик из ландшафта (не ratified, гипотезы): Spec Alignment Rate · Steering Ratio · Change-Failure-Rate-в-паре-с-throughput (Augment) · PR Revert Rate / Change Fail % / DXI (DX/GetDX) · cost per completed task.

## 10. Ландшафтные референсы (происхождение: ВЕБ-ДОБОР 2026-07-28, Informed Fetch; триангуляция частичная — пометки честности в скобках)

**Churn/деградация кода:** GitClear «Maintainability Gap» 01.2026 (дублирование +81% с 2023, рефакторинг 21%→3.8%, дубли:рефакторинг ≈5:1) — gitclear.com/the_ai_code_quality_maintainability_gap (корреляция, не каузальность); SlopCodeBench arXiv:2603.24755 03.2026 («human code stays flat, agent code deteriorates with each iteration»); «An Endless Stream of AI Slop» arXiv:2603.27249.

**Процессный оверхед SDD-фреймворков:** rushis.com обзор «The Case Against SDD» 03.2026 («waterfall in markdown», «80% времени на чтение»); Kiro-кейс 5000 vs 800 строк; Martinelli «Why SDD Tools Fail in the Enterprise» 03.2026; Wattenberger/Augment «What spec-driven development gets wrong» 02.2026 (спека устаревает быстрее поддержки, агенты уверенно исполняют устаревший план); Cross-Component Interference arXiv:2605.05716 (больше scaffolding → отрицательная предельная отдача); таксономия arXiv:2606.04967 (trade-off «глубина процесса vs портируемость»). Контр-голос: HN «Ask HN: still using SDD?» — спеки ценны для brownfield/сложного.

**Multi-agent пределы:** MAST arXiv:2503.13657 (NeurIPS 2025; 14 failure modes: дизайн-спецификация / межагентная рассогласованность / верификация); Cognition «Don't Build Multi-Agents» 06.2025 (дефолт — single-threaded); Anthropic multi-agent research system 06.2025 (multi-agent ≈15× токенов чата; coding — плохой кандидат: общий контекст, компаундинг ошибок); «LLM as a Broken Telephone» ACL 2025 + «Agent Drift» arXiv:2601.04170 (препринт, осторожно) — деградация интенции в цепочках нелинейна, пороговая.

**Specification gaming / «зелёные гейты»:** RepoRescue arXiv:2607.01213 (pass rate 37–52% → 20–24% без правок тестов); SpecBench arXiv:2605.21384 (хакинг архитектурными обходами); OpenAI снял SWE-bench Verified 23.02.2026 (59.4% дефектных тестов); EvilGenie arXiv:2511.21654 / ImpossibleBench; Anthropic «Natural Emergent Misalignment from Reward Hacking» arXiv:2511.18397; «vibe testing» (тесты без ассертов, дата не подтверждена).

**Измерение факта vs ощущения:** METR RCT 07.2025 (−19% фактически при +20% ощущаемого ускорения; snapshot early-2025, генерализация ограничена авторами; follow-up 02.2026 не прочитан); DORA 2025 «AI productivity paradox» (individual output растёт, org delivery плоский; проценты из PDF не подтверждены первично); DX/GetDX метрики 2025; Faros «+98% PR volume без улучшения DORA-метрик» (вторичная цитата, не триангулирована); Gartner «40% agentic-проектов отменят к 2027» (не подтверждено первично).
