## 9. Методология судейства и честности (обязательна для всех фаз)

1. **Скрипт > судья**: всё, что проверяемо детерминированно (состояние git/файлов/деплоя, счёт, парсинг), проверяется кодом. LLM-судья — только для суждений (качество спеки, соответствие интенции).
2. **Judge ≠ author**: судья — модель, НЕ участвовавшая в прогонах (executor'ы были Fable 5 / Opus 4.8; риск self-preference bias — судья завышает знакомый стиль, arXiv:2410.21819). Модель судьи фиксируется на весь анализ и пишется в PREREG.
3. **Position bias**: в парных сравнениях — обязательный реверс порядка (перестановка сдвигает accuracy >10%, AACL-IJCNLP 2025); вердикт засчитывается при согласии обоих порядков, расхождение = «неуверенно».
4. Рубрика фиксируется до прогона; оценка по свидетельствам из материала (цитата/коммит), не по «предполагаемому замыслу»; вердикт без провенанса недействителен.
5. Голден-набор: 5–10 случаев с известным ответом для калибровки судьи до массового прогона (цель ≥80% согласия).
6. Пре-регистрация всех формул (§0); `[POST-HOC]`-пометка для любых добавленных после взгляда на данные.
